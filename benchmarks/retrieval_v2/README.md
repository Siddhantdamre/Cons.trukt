# Regulatory Retrieval Benchmark v2

Version 2 replaces synthetic permit notes with frozen, paraphrased excerpts
derived from official OSHA, FEMA, EPA, and U.S. Department of Justice
accessibility pages. It adds paraphrases, neighboring-rule distractors, and
out-of-domain queries that the retriever must reject.

The corpus records the agency and source URL in each document's metadata. It is
a reproducible retrieval fixture, not a substitute for checking the current
regulation or local code.
